# Tchilo

**Tchilo** é a rede social em [tchilopop.com](https://tchilopop.com) para partilhar fotos, vídeos, stories, reels e mensagens.

## Produto

- Contas e autenticação na nuvem
- Feed, stories, reels e mensagens
- Perfis públicos e privados
- Media e dados de conta sincronizados entre dispositivos
- Tchilo Premium e selo verificado (subscrição)

## Site e app

- Web: https://tchilopop.com
- Suporte: suporte@tchilopop.com
- Privacidade: https://tchilopop.com/privacidade/
- Termos: https://tchilopop.com/termos/
- Sobre: https://tchilopop.com/sobre/

## Nota técnica

Este repositório contém o cliente web e a configuração da app móvel (Capacitor). O backend de produção usa Supabase (auth, base de dados, storage) e pagamentos via Paddle.

Não é uma demonstração local: o produto em produção opera com contas e conteúdos na nuvem.
